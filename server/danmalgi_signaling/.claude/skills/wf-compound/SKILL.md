# wf-compound — 5단계 실행 절차

`compounder` 에이전트의 실행 지침. 목표: 이번 사이클의 마찰·실수·발견을 시스템에 되먹여 다음 사이클을 더 낫게 만든다(복리). "같은 실수를 두 번 하지 않는 하네스".

## 절차

1. **사이클 통독** — `.claude/workflow/<slug>/01`~`04`를 읽는다. 특히 `03_work.md`의 계획 이탈과 `04_review.md`의 blocking 발견사항에 학습이 숨어 있다.
2. **교훈 추출** — 다음을 찾는다:
   - **반복될 함정** — 구조적이라 다시 걸릴 실수 (예: fx 배선 누락, proto 변경 시 mapper 갱신 누락).
   - **효과적 패턴** — 잘 통해 재현하고 싶은 접근.
   - **하네스 마찰** — 단계 간 데이터 전달 끊김, 리뷰가 놓친 유형 등.
3. **일반화 판정** — "이 사이클에만 맞는 좁은 사실"은 버린다. 일반화 가능한 것만 남긴다.
4. **올바른 곳에 반영:**
   | 교훈 유형 | 반영 대상 |
   |----------|----------|
   | 프로젝트 규칙/함정 | `CLAUDE.md` |
   | 단계 실행 방식 개선 | 해당 `wf-*` 스킬 |
   | 에이전트 역할/누락 | 해당 `.claude/agents/*.md` |
   | 트리거 누락 | 스킬 description |
5. **변경 이력 갱신** — `CLAUDE.md` 하네스 섹션 테이블에 날짜·변경·대상·사유 기록.
6. **출력** — `05_compound.md` 작성.

## 산출물 형식 (`05_compound.md`)

```markdown
# 5단계: 학습 축적 — <제목>

## 추출한 교훈      (각: 무엇을 배웠나 · 왜 반복될까 · 어디에 반영했나)
## 반영 내역        (수정한 파일 + 변경 요약)
## 반영 안 한 것    (축적 가치 없다고 판단한 것 + 이유)
```

## 원칙

- **일반화하라** — 파일명이 아니라 원리로 기록.
- **중복 금지** — 이미 있는 규칙은 강화하되 새로 만들지 않는다. 틀린 규칙은 삭제.
- **최소 침습** — 큰 재작성보다 정확한 한 줄. 컨텍스트는 공공재다.
- 축적할 게 없으면 억지로 만들지 않는다 ("이번 사이클 축적 없음" + 근거 기록).
- 규칙 충돌 시 삭제·병합을 사용자에게 확인한다.
